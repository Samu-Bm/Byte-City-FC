# 🧭 Planificación

> Proyecto de **Lenguajes de Marcas** · Ciclo Superior DAW · Byte City FC

**Estado de la implementación:** está implementada la portada principal en `index.html` (en la raíz), con navegación, hero con lema, próximo partido y resumen del club. Los recursos gráficos se encuentran organizados en `img/` y la base de estilos está inicializada en `css/base.css`. Las páginas interiores se estructuran en `pages/`. Consulta el [README](../README.md) para el inventario completo.

Se plantea el proyecto como el desarrollo de un producto web profesional para un cliente: el club ficticio **Byte City FC**.

**Objetivo:** diseñar y desarrollar un sitio web estático, accesible, responsive y bien estructurado semánticamente.

**Metodología por fases**

| Fase | Contenido | Entregable |
|---|---|---|
| 1. Planificación | Sitemap, mockups, guía de estilo | Documentación completa y sitemap actualizado |
| 2. HTML5 | Maquetación semántica de las páginas previstas | Portada implementada; páginas interiores planificadas en `pages/` |
| 3. CSS3 | Estilos base → layout (Flexbox/Grid) → responsive (Mobile First) | En desarrollo; `css/base.css` iniciado |
| 4. Validación | W3C HTML y CSS, revisión de accesibilidad | Pendiente de comprobación |
| 5. Entrega | Repositorio en GitHub con README | Repositorio activo y versionado en GitHub |

> 📱 **Responsive:** se aplicará en la fase 3 con estrategia Mobile First y `@media queries`. Queda pendiente de desarrollo.
